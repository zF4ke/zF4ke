[Website](https://www.modernbazaar.dev/). |

Runs RealSense-based ORB-SLAM3 and YOLO person detection through DeepStream/TensorRT on a Jetson. MAVLink controls each mode independently, while a supervisor restarts failed processes. |
| [Timebox](https://github.com/zF4ke/timebox) | 🗓️ A desktop scheduler that turns plain-language tasks and deadlines into a weekly study plan. Five specialist AI agents critique and vote on drafts, while a planner revises the schedule toward a configurable approval quorum. Exports calendar files and includes a benchmark suite for comparing model quality and cost. [Website](https://zf4ke.github.io/timebox/). |
| [Poeta](https://github.com/zF4ke/poeta) | ✍️ A writing app for rap and poetry with a custom Portuguese phonetic rhyme engine and pronunciation-based English rhymes. Suggests perfect and near rhymes, tracks rhyme schemes and syllable counts, and saves drafts locally without an account. Optional AI helps continue or rewrite lines. [Try it](https://poeta.zf4ke.me/). |
| [Book2English](https://github.com/zF4ke/Book2English) | 📖 A PDF reader that translates text into English or Portuguese and fits it back into the original page layout, preserving illustrations and columns. PDF rendering and translation caching happen in the browser; translation uses OpenRouter with your own API key. [Try it](https://book2english.zf4ke.me/). |
| [Buckshot Roulette Solver](https://github.com/zF4ke/Buckshot-Roulette-Solver) | 🎯 An offline desktop solver for Buckshot Roulette. Enter the visible round state and a Python engine uses memoized expectimax with time-bounded iterative deepening to recommend a move, estimate its odds, and explain the choice. Electron and React provide the interface. [Download](https://github.com/zF4ke/Buckshot-Roulette-Solver/releases). |
| **Traveller** (private) | 🧙‍♂️ A multiplayer mystery RPG played through Discord, where solving ciphers drives the story and player progression. A platform-independent TypeScript engine runs data-driven campaigns, while a Next.js dashboard supports content authoring and playable previews. |
